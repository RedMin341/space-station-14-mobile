# SS14 Фобос — экспериментальная Android-сборка

Отдельная ветка `ss14-fobos-276`; существующая `ss14-touch` остаётся на движке 292.
Приложение `io.ss14.touch.fobos276` устанавливается рядом с `io.ss14.touch.personal`.

## Зафиксированные исходники

- Content: `dead-space-server/space-station-14-fobos`, `94c8636c48eb4d5797a5037f00438917f925337b`.
- RobustToolbox: `dead-space-server/RobustToolbox`, `b55b7ecd9d9cfa0ca6c4aaaa419b11d497a3c30b`, версия 276.0.0.
- Базовая Android-оболочка: SolomonNumb1/space-station-14-mobile, bfe5ef1.

Workflow `Build SS14 Fobos 276` получает эти исходники, применяет отдельные патчи,
формирует архив только ресурсов движка и собирает подписанный APK.
Клиентский код Фобоса встроен в APK; ресурсы контента скачиваются с сервера.
Проверка fork/engine/content revision не допускает смешивания разных сборок.
После изменения версии сервера требуется обновить исходники и APK.

Сенсорный слой перенесён из Android-порта: джойстик, кнопки, редактор расположения,
прокрутка и управление окнами. Автономная песочница в этой сборке недоступна:
полные ресурсы контента берутся с Фобоса при подключении.

## Проверка

Успешная сборка APK сама по себе не подтверждает работу на устройстве.
Нужна проверка входа в лобби и раунд на Huawei CTR-L91, графики, чата,
управления и сохранения пользовательского расположения кнопок.
При ошибке приложить отчёт LOGS с указанием версии приложения.

При переносе сохранены исходные лицензии и авторство проектов.
