# Экспериментальная автономная песочница

Отдельное приложение `io.ss14.touch.sandbox276`. Рабочий клиент Фобоса остаётся установленным.
Основа: Android-порт https://github.com/SolomonNumb1/space-station-14-mobile, публичный Fobos content
94c8636c48eb4d5797a5037f00438917f925337b и RobustToolbox 276
b55b7ecd9d9cfa0ca6c4aaaa419b11d497a3c30b. Редактировал Чёрный Котик.

Сервер запускается в отдельном Android-процессе `:sandbox`, клиент — в `:game`.
Ресурсы встроены в APK, авторизация не используется. UDP слушает только
127.0.0.1:12121; публичный список серверов, HTTP status и метрики отключены.
Админские права выдаёт штатный `console.loginlocal` только локальному игроку.
Рабочий онлайн-клиент и его загрузки не изменяются.

В комнате: 16×16 клеток, атмосфера и фоновое освещение; инструменты на столе,
шкафы, ящик, рюкзак, аптечка, фонарик, уточка, банановая кожура и кот.
Кнопки: ПЕСОЧНИЦА (B), ПРЕДМЕТЫ (F5), АДМИН (F7).
Штатная песочница позволяет создавать предметы и плитки, получать полный
доступ, становиться админ-призраком и возрождаться.

Каждый запуск сервера загружает комнату заново. Раскладка и профиль сохраняются.
Закрытые серверные модули Фобоса не входят в приложение. Это не копия рабочего
сервера. Некоторые общие прототипы могут ссылаться на отсутствующие закрытые
данные. Самые тяжёлые инструменты (массовое создание сущностей, взрывы) могут
перегрузить телефон.

Сборка: workflow android-release.yml в ветке ss14-offline-sandbox.
Сначала штатные патчи, prepare-fobos.py, затем prepare-offline.py. Последний
проверяет ожидаемые фрагменты закреплённого исходного кода и генерирует карту.
SQLite 3.50.4 собирается из проверенного SHA-256 исходного архива через NDK.
Подпись использует постоянный ключ существующего проекта.

Проверка на телефоне обязательна: авиарежим, запуск/остановка/повторный запуск,
подбор нужного инструмента из кучки, шкаф/рюкзак, создание предмета, админ-призрак,
возрождение, сохранение раскладки. При ошибке открыть журнал локального сервера.
Компиляция APK сама по себе не подтверждает прохождение этих проверок.
